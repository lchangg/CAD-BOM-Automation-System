# DWG to DXF map

The existing conversion step invokes an externally installed LibreDWG from the local `work/libredwg` directory. Real DWG/DXF inputs and the converter binaries are intentionally excluded from the open-source copy. See [`docs/third-party-tools.md`](../../docs/third-party-tools.md) and [`THIRD_PARTY_NOTICES.md`](../../THIRD_PARTY_NOTICES.md) for setup and licensing notes.
